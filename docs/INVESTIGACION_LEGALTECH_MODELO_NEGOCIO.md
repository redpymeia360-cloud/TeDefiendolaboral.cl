# Investigación legaltech y modelo de negocio

Este documento acompaña la demostración de Te Defiendo Laboral.cl.

## Propuesta de valor

- Orientación laboral accesible desde web y aplicación instalable.
- Comunidad de networking con perfiles, publicaciones, archivos y avisos.
- Plan Básico para presencia profesional y publicaciones simples.
- Plan Premium para contenidos exclusivos, herramientas, casos, archivos y mayor visibilidad.
- Administración de usuarios, categorías, publicaciones y permisos.

## Ingresos sugeridos

- Membresías mensuales Básica y Premium.
- Patrocinios de empresas y partners.
- Servicios de asesoría, revisión documental y capacitación.
- Eventos, talleres y contenido especializado.
- Implementaciones personalizadas para empresas, sindicatos y comunidades.

## Alcance técnico

La versión publicada en GitHub Pages funciona como demostración estática y PWA. Para uso multiusuario real debe conectarse a Supabase, activar autenticación, ejecutar el esquema SQL y configurar almacenamiento y políticas de seguridad.
