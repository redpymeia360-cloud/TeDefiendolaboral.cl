App Web Progresiva

Instalable en Android, iPhone y escritorio

La App funciona como PWA. Puede instalarse desde Chrome en Android y desde Safari en iPhone usando “Agregar a pantalla de inicio”.

  • Responsive para Android, iPhone, tablets y computadores.
  • Service Worker para caché básico y carga rápida.
  • Base de datos interna para modo demo y conexión real preparada para Supabase.
  • Compatible con GitHub Pages para publicar el sitio.
