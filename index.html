App Web Progresiva

Instalable en Android, iPhone y escritorio

El proyecto funciona como PWA: el usuario puede abrirlo desde GitHub Pages o dominio propio y agregarlo a la pantalla de inicio como aplicación. Incluye funcionamiento offline básico mediante Service Worker.

  • Responsive para Android, iPhone, tablets y computadores.
  • Base de datos local con IndexedDB para contacto, consultas, foro y newsletter.
  • Exportación de registros en JSON y CSV para respaldo.
  • Archivo de configuración preparado para conectar luego a Supabase o Firebase.
  • Compatible con GitHub Pages porque no requiere servidor propio para funcionar en modo local.

Instalación en celulares

Cómo instalar la App

Android

Abre el sitio en Chrome y presiona “Instalar” o “Agregar a pantalla principal”.

iPhone

Abre el sitio en Safari, toca Compartir y luego “Agregar a pantalla de inicio”.

Computador

Abre el sitio en Chrome o Edge y toca el ícono de instalar en la barra del navegador.
